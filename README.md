# Orbiter

Orbiterは、ElectronとC言語を組み合わせて開発された、高速かつモダンなWindows向けファイルエクスプローラーです。洗練されたUIと軽快な動作を両立し、日常のファイル管理をより快適にします。

## 特徴
- **モダンで美しいUI**: カスタム可能なテーマ（ライト/ダークなど）に対応
- **高速なファイル操作**: C言語によるバックエンド処理で、ファイルのリスト表示や検索を高速に実行
- **豊富なビューモード**: 特大アイコンからコンパクトリストまで様々な表示方法をサポート
- **便利なコンテキストメニュー**: 独自実装による洗練された右クリックメニュー
- **プレビュー機能**: サイドペインおよび別ウィンドウでのファイル内容のクイックプレビュー
- **クイックアクセス＆お気に入り**: よく使うフォルダに素早くアクセス可能

## インストールと実行方法
本アプリはインストーラー不要のポータブル形式で提供されています。

1. [Releases](https://github.com/USERNAME/orbiter/releases) ページから最新の `Orbiter-x.x.x-win.zip` をダウンロードします。
2. ZIPファイルを任意の場所に展開（解凍）します。
3. 展開したフォルダ内の `Orbiter.exe` をダブルクリックして起動します。

> [!WARNING]
> **SmartScreen（WindowsによってPCが保護されました）が表示された場合**
> 
> 本アプリは現在、コード署名（デジタル署名）が行われていないため、初回起動時にWindowsのSmartScreen機能によって警告画面が表示されます。これは未知のアプリケーションに対するWindowsの標準的な仕様です。
> 
> 起動するには、警告画面の左側にある **「詳細情報」** をクリックし、右下に表示される **「実行」** ボタンをクリックしてください。

## 開発ビルド方法
開発環境を構築してご自身でビルドを行う場合は、以下の手順に従ってください。

```bash
# 依存関係のインストール
cd frontend
npm install

# 開発モードで起動
npm start

# リリースビルド（dist/ 以下にZIPパッケージが生成されます）
npm run build
```

## 既知の制限事項
- 現状はWindows専用です（Mac/Linuxには対応していません）。
- タブ機能は現在開発中であり、今後のバージョン(v1.1以降)で追加予定です。
- 管理者権限が必要なファイル操作には現在対応していません。

# Orbiter

Orbiterは、ElectronとC言語を組み合わせて開発された、高速かつモダンなWindows向けファイルエクスプローラーです。洗練されたUIと軽快な動作を両立し、日常のファイル管理をより快適にします。

## 特徴
- **モダンで美しいUI**: カスタム可能なテーマ（ライト/ダーク/サクラ/ミッドナイト等）に対応し、ユーザー独自のカスタムテーマも作成可能
- **高速なファイル操作**: C言語によるバックエンド処理で、膨大なファイルのリスト表示や検索を極めて高速に実行
- **高度なタブ管理**: ブラウザのようなタブ機能を搭載。ピン留め、順序入れ替え、複数ウィンドウへの切り出しにも対応
- **豊富なビューモード**: 特大アイコンから詳細リスト、コンパクト表示まで、用途に合わせた多彩な表示モード
- **便利なコンテキストメニュー**: 独自実装による洗練されたメニューから、ファイル操作やパスのコピー、管理者権限での実行が可能
- **クイックプレビュー**: サイドペインでの即時プレビューに加え、別ウィンドウでの詳細プレビュー機能も搭載
- **クイックアクセス＆お気に入り**: よく使うフォルダや重要な場所へワンクリックでアクセス
- **管理者権限への対応**: 保護されたディレクトリでのファイル操作時、安全に管理者権限への昇格を要求可能

## インストールと実行方法
本アプリはインストーラー不要のポータブル形式で提供されています。

1. [Releases](https://github.com/USERNAME/orbiter/releases) ページから最新の `Orbiter-x.x.x-win.zip` をダウンロードします。
2. ZIPファイルを任意の場所に展開（解凍）します。
3. 展開したフォルダ内の `Orbiter.exe` をダブルクリックして起動します。

> [!WARNING]
> **SmartScreen（WindowsによってPCが保護されました）が表示された場合**
> 
> 本アプリは現在、コード署名（デジタル署名）が行われていないため、初回起動時にWindowsのSmartScreen機能によって警告画面が表示されます。これは未知のアプリケーションに対するWindowsの標準的な仕様です。
> 
> 起動するには、警告画面の左側にある **「詳細情報」** をクリックし、右下に表示される **「実行」** ボタンをクリックしてください。

## 開発ビルド方法
開発環境を構築してご自身でビルドを行う場合は、以下の手順に従ってください。

```bash
# 依存関係のインストール
cd frontend
npm install

# 開発モードで起動
npm start

# リリースビルド（dist/ 以下にZIPパッケージが生成されます）
npm run build
```

**もしくは、`build_release.ps1`を実行することでもビルドが可能です。これはC言語のビルドも一緒に行ってくれます。**

## 既知の制限事項
- 現状はWindows専用です（Mac/Linuxには対応していません）。
- ネットワークドライブの一部機能において、表示が制限される場合があります。

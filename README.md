Orbiter（オービター）は、ElectronとC言語を融合して構築された、Windows専用のファイラーです。

**「最小の動作で、最大限の開発効率を。」**

画面とコンソールの往復による「手数の無駄」や「思考の途切れ」を徹底排除。従来のコンソール一体型ツールを凌駕する高度な機能性で、エンジニアの開発を強力にサポートします。

洗練されたGUIと、スマートなレスポンス。圧倒的な実利と革新性を備えた、すべての開発者のための次世代ファイラーです。

## 特徴・主要機能

### 1. 圧倒的なパフォーマンス＆低負荷設計
- **C言語バックエンドコア**: 膨大なディレクトリの走査、高速リスト表示、文字列表査などをC言語モジュールがバックグラウンドで担い、瞬時のレスポンスを実現。
- **`orbiter-media://` 独自プロトコル**: Base64変換等のJSメモリ負荷を完全に撤廃し、100MB超の超大容量画像や8K解像度の画像でもGPUで高速レンダリング（JS Heap消費は常時0%）。
- **常時省電力デバイス監視**: 定期監視（ポーリング）を行わないWin32ネイティブのメッセージフック方式を採用。バックグラウンドで**CPU/メモリの消費ゼロ**で、USBメモリなどの着脱をミリ秒検知してツリービューを自動更新。

### 2. 高機能なファイル管理ワークフロー
- **ブラウザライクなタブシステム**: ピン留め、ドラッグによる順序入れ替え、複数ウィンドウへのドラッグアウト切り出しに完全対応。
- **直感的な操作空間**: 特大アイコンから超コンパクト表示まで対応する表示モード切替、管理者権限へのスムーズな昇格、パスの高速コピー、詳細クイックプレビューウィンドウなどを完備。
- **ワンタップで開けるプレビュー機能**:ファイル選択からスペースキー1つでプレビュー画面が立ち上がります。PDFの閲覧や動画の視聴も別アプリへ遷移することなく行えるため、開発のステップを止めることがありません。

### 3. 没入感溢れるUI
- **アクリルぼかし階層構造**: メインのファイルリスト部分は背後の壁紙が見える `12px` の透き通ったブラーに抑え、サイドバーやヘッダー等の操作フレームは重厚感ある `24px` のすりガラスに設定。Fluent Design に基づく極上の立体感を構築。
- **色彩の自動同調 (Accent Sync)**: 壁紙の最上部を Canvas で自動解析し、OS標準の操作ボタン背景色を壁紙に完全同化。さらにアプリのハイライト色（枠線やボタン選択色）が壁紙の基調色にリアルタイムで連動。
- **壁紙カタログギャラリー**: ホームフォルダ内の画像を再帰スキャンして美しく一覧表示。すでに履歴にある重複画像やアプリアセットの自動スキップ機能など、徹底的なクリーンフィルタリングを搭載。

## インストールと起動方法

本アプリは、レジストリを汚さない**ポータブル（解凍即起動）形式**で提供されています。

1. [Releases](https://github.com) ページから最新の `Orbiter-2.1.0-win.zip` をダウンロードします。
2. ダウンロードしたZIPファイルを任意の場所（デスクトップなど）に展開（解凍）します。
3. 展開したフォルダ内にある `Orbiter.exe` をダブルクリックして起動します。

> [!WARNING]
> **SmartScreen（WindowsによってPCが保護されました）が表示された場合**
> 
> 本アプリは個人開発のポータブルアプリであるため、初回起動時にWindows SmartScreenの警告画面が表示される場合があります。
> 
> **【回避手順】**
> 1. 警告画面のメッセージ内にある **「詳細情報」** をクリックします。
> 2. 出現した右下の **「実行」** ボタンをクリックすると、以降は警告なしで安全に起動できます。

## 🛠️ 開発とビルド方法

ソースコードから手動でビルド、または開発モードで実行する場合は以下のコマンドを使用します。

### 依存関係のセットアップ
```powershell
cd frontend
npm install
```

### 開発モードでの起動
```powershell
npm start
```

### パッケージのビルド (ポータブルZIPの生成)
```powershell
# C言語サーバーモジュールのビルドとElectronアプリのビルドを一括で行う自動スクリプト
.\build_release.ps1
```
> ※ ビルドが成功すると、`frontend/dist/` ディレクトリ配下に `Orbiter-2.1.0-win.zip` が自動生成されます。

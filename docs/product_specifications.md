# Orbiter 製品仕様書 (Product Specifications)

## 1. アプリケーション概要
Orbiterは、Electronをフロントエンド、C言語をバックエンドに使用した、高速でモダンなWindows向けファイルエクスプローラーです。

## 2. 主要機能

### 2.1 ファイル管理 (Filer)
- **多彩なビューモード**: 詳細リスト、コンパクトリスト、特大/大/中/小アイコン。
- **高速な操作**: ファイルの一覧表示、コピー、切り取り、貼り付け、削除、名前変更。
- **クイックアクセス**: よく使うフォルダのお気に入り登録とサイドバー表示。
- **検索**: インクリメンタルなファイル検索機能。

### 2.2 統合ターミナル (Integrated Terminal)
- **コマンドライン実行**: ウィンドウ下部に配置された入力エリアから即座にコマンドを実行。
- **カレントディレクトリ同期**: フィラーで開いているディレクトリがターミナルのカレントディレクトリとして反映。

### 2.3 プレビュー機能 (Preview)
- **サイドペインプレビュー**: スペースキーでファイル内容（テキスト、画像等）を即座に確認。
- **プレビューウィンドウ**: 必要に応じて別ウィンドウでプレビューを表示。

### 2.4 デザインとカスタマイズ (Theme)
- **テーマプリセット**: ライト、ダーク、サクラ、スカイなどの多彩な配色。
- **ユーザーカスタムテーマ**: JSON形式による独自の配色設定の読み込み。
- **ズーム・フォント調整**: UIの拡大率やフォントサイズの柔軟な変更。

## 3. UI構成 (Layout)
- **ツールバー**: 戻る/進む/更新、パス入力、検索ボックス。
- **アクションバー**: 新規作成、基本操作（コピー等）、表示設定、並べ替え設定。
- **メインエリア**:
  - 左: サイドバー（ツリービュー、クイックアクセス）。
  - 中央: ファイルリスト。
  - 右: プレビューペイン（非表示可能）。
- **ボトムエリア**: 統合ターミナル。

## 4. 技術スタック
- **Frontend**: Electron, HTML5, CSS3, JavaScript.
- **Backend**: C (HTTP Server via socket), local binary integration.
- **Packaging**: Portable ZIP distribution.
